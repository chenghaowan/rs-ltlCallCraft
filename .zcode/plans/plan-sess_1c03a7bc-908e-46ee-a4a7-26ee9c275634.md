# rs-ltlCallCraft — iroh 通讯模块(egui 飞书风界面)

## Context

ltl-manage 的聊天(会话/消息/通讯录/WS 推送)目前耦合在 FastAPI 后端 + Tauri/React 前端里。按既有拆分惯例(meetingrecord、3dPDM、ai-runtime 的模式),把通讯模块拆成独立 Rust 项目 **rs-ltlCallCraft**(当前为空目录,全新创建):

1. 通讯层用 **iroh + iroh-gossip(0.101)**:消息实时收发走 gossip 主题(每个会话一个 TopicId),服务端常驻一个 iroh 节点作为引导节点 + 历史留档;
2. 服务器端**对接 YM Auth 登录**(yimei2000.cn,token 校验/手机号登录,首次登录自动登记用户,名单自动同步),发本服务自己的 JWT;
3. 附件(图片/文件)走聊天服务器 HTTP 上传/下载(与现有 ltl-manage 行为一致);
4. **egui/eframe 0.37**(与生态 pointtofix、ai-runtime 同版本)做飞书风格界面,是本项目主入口 `cargo run -p ltl-chat-gui`;
5. 附带 **clap CLI** 与 **`.agents/skills` skill 文档**;
6. **ltl-manage 完全不动**(不注册插件、不改 gitrecord.md)。

iroh 当前 API(已核实 docs.iroh.computer/examples/chat 与 docs.rs/iroh-gossip 0.101.0):`Endpoint::builder(presets::N0).secret_key(..).bind()`、`Gossip::builder().spawn(endpoint)`、`Router::builder(endpoint).accept(iroh_gossip::ALPN, gossip)`、`gossip.subscribe_and_join(topic, bootstrap_endpoint_ids)`、`sender.broadcast(bytes)`、`Event::Received`(内容哈希去重 → 消息需带 nonce)。

## crates/core(ltl-chat-core)

- **领域类型**(serde):`User{id,ymid,name,phone,email,avatar,is_online}`、`Conversation{id,title,conv_type:single|group,topic_id:[u8;32],members,last_message}`、`Message{id:[u8;16],conversation_id,sender_id,sender_name,msg_type:text|image|file,content,reply_to,attachments,is_recalled,created_at_ms}`、`AttachmentMeta{id,name,size,mime,url}`(修正旧系统 type/image 落库为 text 的 bug,统一 msg_type)。
- **gossip wire 消息** `GossipMessage{ message: Message, nonce:[u8;16] }`,serde_json 编解码(照官方示例)。
- **iroh 封装** `ChatNode`:启动 Endpoint(密钥持久化到 `node.key`)、Gossip、Router;`join(topic, bootstrap=[server_endpoint_id]) -> (GossipSender, GossipReceiver)`;`endpoint_id()`。
- **本地存储** rusqlite 0.37(bundled) `client.db`:users / conversations / messages(按 id 去重)/ read_cursors(未读游标)/ settings(server_url、token、profile)。
- **YM Auth 客户端**:reqwest 调 `YM_AUTH_API_BASE` 的 `/auth/me`、`/auth/phone/login`、`/users/list`;移植 `backend/src/app/modules/auth/service.py` 的 **`demo_` 前缀 token → 本地演示用户分支**(本地无外网也能联调)。

## crates/server(ltl-chat-server)

axum 0.8 + sqlx(sqlite)+ clap。`ltl-chat-server serve --addr 127.0.0.1:8901 --data-dir ./data [--ym-auth-base https://yimei2000.cn/auth]`。

- **表**(对齐 ltl-manage 语义):users(ymid unique、is_online、last_active_at)/ conversations(topic_id 唯一)/ conversation_members(role)/ messages(uuid 主键)/ message_attachments(先传后绑)。
- **Auth**:`POST /auth/login {ym_auth_token}`(demo_ 分支直通)→ 校验 YM → upsert 用户(=登记)→ 签发 JWT HS256 24h;`POST /auth/phone/login {phone, username?}` 代理 YM;`GET /auth/me`。
- **Roster**:`GET /users`(先从 YM `/users/list` 同步 upsert,远端缺失置 is_active=0)、`GET /users/online`(last_active < 120s)、`POST /heartbeat`。
- **会话**:`GET/POST /conversations`(单聊幂等复用,照 `conversation/service.py::find_single_conversation`;建群时生成随机 TopicId 并让服务端节点立即 join 该 topic)、`POST /{id}/members`、`GET /{id}/messages?after_id=&limit=`(历史补齐,升序)。
- **附件**:`POST /files/upload`(multipart → `uploads/`)、`GET /files/{id}`。
- **常驻 iroh 节点**:启动即 spawn Endpoint+Gossip+Router;对每个会话 topic `subscribe(topic, [])` 并持久化收到的 GossipMessage 到 DB(dedup by uuid)——离线成员靠 HTTP 历史补齐追上。登录响应带 `server_endpoint_id` 供客户端作 gossip bootstrap。

## crates/cli(ltl-chat-cli)

clap derive,配置存 `%APPDATA%\ltl-chat\config.toml`(server url、token,`--profile` 支持多实例):`login --phone/--token`、`whoami`、`users`、`conversations`、`create-dm --user`、`create-group --title --members a,b,c`、`send --conv <id> --text`(临时起 iroh 节点 broadcast,`--wait-secs` 默认 2)、`history --conv`、`listen --conv`(长驻收 gossip,联调用)。

## crates/gui(ltl-chat-gui)— 飞书风界面(主入口)

eframe 0.37;tokio runtime 跑在独立线程,GUI↔后端用 mpsc 通道(生态 ai-runtime/pointtofix 模式);数据目录 `%APPDATA%\ltl-chat\<profile>`。

- **登录页**:服务器地址(默认 http://127.0.0.1:8901)+ 手机号/用户名登录 + YM token 粘贴登录 + 演示登录。
- **主界面三栏**:
  - 左导航栏(~56px):logo、消息/通讯录切换图标、底部本人头像;
  - 中栏(~260px):搜索框;会话列表按 **置顶/单聊/群聊** 分组(移植 `frontR/src/utils/convType.ts` 逻辑),行 = 彩色首字头像(颜色用 `colors.ts` 的 stringToColor,单聊加在线绿点)+ 标题 + 最后消息预览 + 时间 + 未读红点 + 📌;通讯录页 = 联系人列表(在线点、搜索、点击发起单聊);
  - 右聊天面板:标题栏(群聊含成员数、拉人入群、置顶);消息气泡(自己 `#3370ff` 右对齐,他人灰底左对齐带头像/名字/时间,撤回灰条,回复引用块);图片消息内嵌显示、文件消息卡片点击下载(egui_extras + image 纹理缓存);输入区 = 多行输入(Enter 发送)+ 表情面板(移植 `utils/constants.ts` EMOJIS)+ 图片/文件按钮(rfd 选文件,图片压缩 ≤256px 移植 `utils/file.ts`)+ 右键菜单(撤回/引用)。
- **后台任务**:gossip 收包循环 → UiEvent;30s 轮询会话列表与在线状态(沿用旧系统节奏);打开会话时 HTTP 历史补齐 + markRead 游标推进;发送乐观插入(临时负 id,回包/回显后替换)。
